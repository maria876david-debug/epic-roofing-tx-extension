# Epic Roofing TX — Roof Size Estimator

Estimate your Houston roof size in squares, plus quick links.

A quick companion for epicroofingtx.com, a Houston roofing referral site. Estimate roof size in squares and reach the site in one click. Estimates are rough only; no prices, reviews or certifications are claimed.

## Download

Installable packages are on the [Releases](https://github.com/maria876david-debug/epic-roofing-tx-extension/releases) page — Microsoft Edge (.zip) and Firefox (.zip).

## Website

https://epicroofingtx.com

## Privacy

No data is collected. The extension runs locally in your browser; no account, no tracking, no remote requests.
